Scanning Workflow

This section describes the detailed scanning workflow from image detection through result delivery.

Step-by-Step Process

  1. Image Reference - The scanner receives the container image reference (name:tag or digest)
  2. Image Pull - The image is pulled from the registry (using provided credentials if private)
  3. Layer Extraction - Container layers are extracted and analyzed
  4. Package Detection - OS and application packages are identified
  5. Vulnerability Matching - Packages are matched against the Qualys vulnerability database
  6. Secrets Scanning - Image layers are scanned for embedded secrets (if enabled)
  7. Report Generation - SARIF and JSON reports are generated
  8. Policy Evaluation - Results are evaluated against thresholds or cloud policies
  9. Result Output - Vulnerability counts and policy result are output for pipeline decisions

Event Processing Steps

  1. Event Capture - Cloud audit log captures the deployment API call
  2. Event Filtering - EventBridge/Event Hub filters for relevant events
  3. Event Parsing - Lambda/Function extracts container image details
  4. Cache Check - DynamoDB/Storage lookup prevents duplicate scans
  5. Registry Registration - Image registry is registered with Qualys (if new)
  6. Scan Submission - On-demand scan request submitted to Qualys API
  7. Polling - Step Functions/Durable Functions poll for scan completion
  8. Result Retrieval - Vulnerability findings retrieved from Qualys
  9. Notification - Results sent to SNS/Service Bus for downstream processing

Scan Caching

To optimize performance and reduce duplicate scans, all integrations implement caching:

Integration Cache Store Default TTL
AWS Fargate/Lambda DynamoDB 24 hours
Azure ACI/ACA Azure Storage Tables 24 hours
Kubernetes Sensor Local cache + Qualys platform Configurable

Cache Key Generation

Cache keys are generated from image identifiers:

cache_key = hash(registry + "/" + repository + "@" + digest)

Using the image digest ensures that even if a tag is reused, a new scan is triggered for different image content.

Result Delivery

Synchronous (CI/CD)

Results are returned immediately to the pipeline:

  • Vulnerability counts available as action outputs
  • Policy result (ALLOW/DENY/AUDIT) determines workflow outcome
  • Reports saved as artifacts for later review

Asynchronous (Cloud)

Results are delivered via notifications:

  • SNS topics for AWS integrations
  • Service Bus for Azure integrations
  • Webhook callbacks for custom integrations

Dashboard (Qualys Platform)

All scan results are available in the Qualys Container Security console:

  • Centralized vulnerability visibility
  • Historical trending and reporting
  • Policy management and compliance tracking
