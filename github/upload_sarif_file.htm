Upload SARIF File on GitHub

You can upload container scan results to GitHub in SARIF (Static Analysis Results Interchange Format) format. The results are displayed in the Security tab under Code scanning alerts, providing centralized visibility into container vulnerabilities.

Upload SARIF Results

Add the github/codeql-action/upload-sarif action after the container scan step:

name: Container Security Scan

on:
  push:
    branches: [main]

jobs:
  scan:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      security-events: write
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Scan container image
        id: scan
        uses: qualys/container-scan-action@v1
        with:
          qualys_access_token: ${{ secrets.QUALYS_ACCESS_TOKEN }}
          qualys_pod: US1
          image_id: my-app:latest

      - name: Upload SARIF results
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: ${{ steps.scan.outputs.sarif_path }}
Important

The workflow must have security-events: write permission to upload SARIF files.

View Results in GitHub Security Tab

After the workflow completes, view the scan results:

  1. Navigate to your repository on GitHub
  2. Click the Security tab
  3. Select Code scanning alerts from the sidebar
  4. View and filter container vulnerabilities

The Security tab displays:

  • Vulnerability severity (Critical, High, Medium, Low)
  • CVE identifiers and descriptions
  • Affected packages and versions
  • Remediation recommendations
  • Alert status (Open, Dismissed, Fixed)

Conditional Upload

Upload SARIF results even if the scan step fails (to capture vulnerability data):

- name: Upload SARIF results
  uses: github/codeql-action/upload-sarif@v3
  if: always()
  with:
    sarif_file: qualys-scan-results.sarif

Custom SARIF File Name

The container scan action generates a SARIF file at the path specified in the sarif_path output. By default, the file is named qualys-scan-results.sarif.

SARIF Report Structure

The SARIF report includes:

  • Tool Information - Qualys Container Security scanner version and rules
  • Results - Individual vulnerability findings with severity levels
  • Locations - Affected packages, layers, and file paths
  • Rule Metadata - CVE details, CVSS scores, and fix recommendations

Filtering Alerts

In the GitHub Security tab, you can filter alerts by:

  • Severity - Critical, High, Medium, Low
  • State - Open, Dismissed, Fixed
  • Branch - Filter by branch name
  • Tool - Filter by scanning tool (Qualys Container Security)

Dismissing Alerts

You can dismiss alerts that are false positives or accepted risks:

  1. Click on the alert in the Security tab
  2. Click Dismiss alert
  3. Select a reason: Won't fix, False positive, or Used in tests
  4. Add an optional comment
